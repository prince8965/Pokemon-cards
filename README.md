# Random Pokémon Card Grid

A lightweight web application that displays a dynamic grid of Pokémon character cards. The core feature of this project is its randomization engine: every time the user refreshes the browser, a completely new, randomized layout of Pokémon cards is generated and displayed on the screen.

## 📸 Preview

![Pokémon Cards Grid] 
*A sample view of the randomized grid featuring characters like Charizard, Gengar, Squirtle, and Pikachu.*

## ✨ Features

*   **Dynamic Randomization:** A JavaScript function shuffles and renders a random selection of Pokémon cards upon every page reload.
*   **Responsive Grid Layout:** The cards are neatly arranged in a grid format that adapts to the screen size for optimal viewing.
*   **Clean User Interface:** Minimalist design focusing on the character artwork with simple bordered cards.

## 🛠️ Technologies Used

*   **HTML5:** Structure and layout of the web page.
*   **CSS3:** Styling the grid layout, card borders, and responsive design.
*   **JavaScript (Vanilla):** Logic for handling the randomization of the Pokémon array and injecting the DOM elements on load.
